# Установка демо на iPhone и iPad

Проект настроен для iOS: идентификатор приложения `com.jericho.strategy`, IL2CPP, iOS 13.0+, альбомная ориентация, безопасные отступы под вырезы экрана и квадратная иконка приложения.

## Что потребуется

- Mac с Xcode и Unity 6.0.0f1.
- Модуль **iOS Build Support** для этой версии Unity. Установить его можно через Unity Hub → Installs → меню версии Unity → Add modules.
- Для установки на собственное устройство — Apple ID и включённый режим разработчика на iPhone. Для TestFlight и распространения другим людям потребуется программа Apple Developer.

## Сборка и запуск на устройстве

1. Распакуйте проект и откройте папку `NasledieUnity` в Unity Hub. Дождитесь импорта ресурсов и автоматического создания сцены `Assets/Scenes/Main.unity`.
2. В Unity откройте **File → Build Profiles**, выберите **iOS**, нажмите **Switch Platform**, затем **Build**. Сохраните Xcode-проект в отдельную папку.
3. Откройте созданный `.xcodeproj` в Xcode, выберите цель `Unity-iPhone`, подключённый iPhone и свою команду подписи в **Signing & Capabilities**.
4. Запустите приложение через **Product → Run**. При первом запуске на телефоне разрешите режим разработчика и подтвердите доверие профилю разработчика, если iOS покажет такой запрос.

Сцену, идентификатор, минимальную версию iOS, backend IL2CPP и иконку выставляет `Assets/Game/Editor/ProjectSetup.cs` при открытии проекта в Unity.

## Граница текущей среды

Исходный Unity-проект подготовлен, но `.ipa` и Xcode-проект здесь не собраны: текущая среда работает на Linux, в ней нет Unity Editor, Xcode, сертификата подписи или подключённого iPhone. Подпись и установка выполняются на Mac владельцем Apple ID.
