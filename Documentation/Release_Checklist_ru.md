# JERICHO — чек-лист до релиза

Сверено 18 октября 2026 года. Это чек-лист базовой древней кампании; будущие DLC, магазин и сетевые функции сюда не входят.

## Закрыто в проекте и проверено headless

- [x] Процедурная кампания, пять эпох, четыре активных пути победы и итог наследия.
- [x] Экономика клеток, рост и миграция населения, районы, дипломатия, война и послевоенное восстановление.
- [x] Действия Strong/Trial ИИ: активные победы, развитие, кризисы и военная инициатива на наборах seed.
- [x] Десять шагов обучения: прогресс отмечается принятыми действиями или просмотром нужной вкладки; шаг можно пропустить.
- [x] Четыре слоя карты: владение, еда, производство и оборона. Неизвестные объекты и невидимые отряды не отображаются.
- [x] Объяснение стратегического курса ИИ: оценка выбранного курса, ближайшая альтернатива и текущие кризисные факторы.
- [x] Размер UI 90–130%, высокий контраст вторичных надписей, отключение/ускорение анимаций и переключатель виброотклика.
- [x] SHA-256 правил и состояния после каждого хода, воспроизведение команд по seed, экспорт отчёта. Журнал после 2000 команд помечается как усечённый.
- [x] Полный headless `CorePlaythrough`, проверка UI bindings и отдельный сценарий replay.

## Обязательные ворота перед публикацией

- [ ] **Открыть проект в Unity 6.0.0f1.** Дождаться импорта, разрешить ошибки/предупреждения компиляции и проверить открытие `Assets/Scenes/Main.unity`.
- [ ] **Пройти Unity Play Mode от новой кампании до финала.** Проверить меню, выбор нации/темпа/сложности, все вкладки, события, дипломатию, войны, активную победу и итог наследия.
- [ ] **Проверить каждый экран и кнопку визуально.** Статические bindings проходят, но они не ловят перекрытие, обрезанный текст, неверное состояние кнопки и ошибки Canvas Layout.
- [ ] **Проверить карту в landscape на телефоне.** Перетаскивание, pinch, кнопки zoom, слои, выбор гексов, длинное и двойное нажатие; отдельно проверить безопасные области iPhone и небольшую ширину экрана.
- [ ] **Проверить анимации и звук в Play Mode.** Ход, перемещение, бой, стройка, переход эпохи, музыка и эффекты; убедиться, что быстрый/выключенный режим не блокирует ввод.
- [ ] **Проверить сохранения в Unity runtime.** Создать ручное и автосохранение, перезапустить игру, загрузить все слоты, импортировать старые схемы, испортить копию файла и прервать запись тестовым завершением процесса.
- [ ] **Измерить производительность на целевых iPhone/iPad.** Время хода, стабильность кадра при карте и анимациях, память, нагрев и размер установки.
- [ ] **Провести пользовательские сессии.** Новички должны пройти обучение и первый час без объяснений автора; записать непонимание, брошенные ходы, длительность партии и случаи тупика/снежного кома ИИ.
- [ ] **Закончить английскую локализацию.** Перевести UI, статьи, события, названия и сообщения; проверить переносы строк и терминологию носителем языка. Сейчас английский не является полноценным языком интерфейса.
- [ ] **Проверить доступность на устройстве.** VoiceOver/экранный диктор, порядок фокуса, масштаб текста, цветовой контраст и реальный Taptic Engine. Текущие UI-настройки не заменяют screen reader integration.
- [ ] **Закрыть информационную изоляцию ИИ.** Перевести все стратегические решения на отдельный `PlayerMapView`, затем прогнать одинаковые наблюдения с разными скрытыми состояниями и подтвердить одинаковые решения там, где информация не видна.
- [ ] **Собрать, подписать и установить iOS-приложение.** Нужны Unity iOS Build Support, macOS с Xcode, Apple signing assets и физическое устройство. Для App Store нужен аккаунт Apple Developer.
- [ ] **Подготовить App Store материалы.** Иконка/скриншоты в размерах Apple, описание и политика конфиденциальности, возрастной рейтинг, тестовая сборка TestFlight и прохождение App Review.

## Запуск доступных автоматических проверок

```sh
dotnet run --project Tests/CorePlaythrough/CorePlaythrough.csproj -c Release
dotnet run --project Tests/CorePlaythrough/CorePlaythrough.csproj -c Release -- replay
python3 Tools/CheckUiBindings.py
git diff --check
```

Headless-прохождение подтверждает правила и воспроизводимость ядра. Оно не заменяет Unity Player, ручную игру, iOS-сборку и тестирование на физическом устройстве.
