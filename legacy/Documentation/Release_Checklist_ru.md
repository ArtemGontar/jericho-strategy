# JERICHO — чек-лист перед релизом

**Сверено:** 18 октября 2026 года. Чек-лист относится к базовой древней кампании; DLC, магазин, платежи, облако и мультиплеер сюда не входят.
**Статус сборки:** Unity-проект и headless-ядро подготовлены; Unity Play Mode и iOS на Intel Mac ещё не приняты. Все практические кейсы и журнал выполнения находятся в [подробном тест-плане](Unity_Test_Plan_ru.md).

## Закрыто в игровом ядре и проверено headless

- [x] Процедурная кампания, пять эпох, четыре активных пути победы и итог наследия.
- [x] Экономика клеток, рост и миграция населения, районы, дипломатия, война и послевоенное восстановление.
- [x] Действия Strong/Trial ИИ: развитие, кризисы, активные победы и военная инициатива на тестовых seed.
- [x] Десять шагов обучения с отметкой принятых действий/просмотра вкладки и свободным пропуском.
- [x] Четыре слоя карты, скрытие неизвестных объектов, стратегическое объяснение курса ИИ.
- [x] Размер UI 90–130%, контраст, настройка анимаций, виброотклик и локальные предпочтения.
- [x] SHA-256 правил/состояния ходов, replay по seed, экспорт диагностики; журнал после 2000 команд помечается усечённым.
- [x] Headless `CorePlaythrough`, отдельный replay сценарий и статическая проверка UI bindings.

Это закрытие игрового ядра, а не приёмка клиента. Статическая проверка кнопок не подтверждает раскладку, правильное действие в Play Mode, сенсорное управление, звук, анимацию или iOS-жизненный цикл.

## Ворота для рабочей демо-версии на Intel Mac

- [ ] Открыть точную версию проекта из `ProjectSettings/ProjectVersion.txt` — **Unity 6000.0.0f1** — на Intel Mac; записать модель, RAM и macOS.
- [ ] Дождаться импорта, закрыть все ошибки компиляции/импорта, проверить сцену `Assets/Scenes/Main.unity` и меню JERICHO.
- [ ] Запустить **JERICHO → Проверить кампанию** и **JERICHO → Проверить игровые материалы**.
- [ ] Повторить доступные .NET и Python-проверки из корня репозитория.
- [ ] Пройти все P0 тест-кейсы и записать статус в журнале `Documentation/Unity_Test_Plan_ru.md`.
- [ ] Пройти новую кампанию в Unity Play Mode от главного меню через первый ход, экономику, вкладки, сохранение/загрузку до активной победы или итогового наследия.
- [ ] Исправить S0/S1 дефекты, повторить затронутые кейсы и полный путь кампании.

Unity 6.0 поддерживает Intel x64/SSE2 на macOS Big Sur 11 или новее с Metal-совместимой графикой; рекомендуемый минимум памяти для Editor — 8 ГБ. Проверять требования по [документации Unity 6.0](https://docs.unity3d.com/6000.0/Documentation/Manual/system-requirements.html). Для Play Mode на Mac Xcode не требуется.

## Дополнительные ворота для iOS

- [ ] Установить в ту же версию Unity модуль iOS Build Support.
- [ ] Убедиться, что версия Xcode совместима с установленной macOS и удовлетворяет Unity 6.0 (Xcode 15+). На Intel Mac использовать Xcode 26 или ниже; Xcode 27 требует Apple silicon. Проверить [матрицу Apple](https://developer.apple.com/xcode/system-requirements) до установки.
- [ ] Экспортировать Xcode-проект, собрать его и установить на физический iPhone под собственной подписью.
- [ ] Проверить landscape, safe area, жесты, сворачивание/возврат, сохранение, звук и ход до финала на реальном телефоне.
- [ ] Измерить время хода, стабильность кадра, память/нагрев на выбранных целевых устройствах; зафиксировать модели и результаты.
- [ ] Проверить VoiceOver, английскую локализацию и доступность текстов после их реализации. Пока это незакрытые релизные блокеры.
- [ ] Провести тесты новичками: обучение, понятность причин миграции/кризиса/войны и длительность партии.
- [ ] Закрыть полную информационную изоляцию планировщика ИИ: стратегические решения должны зависеть от доступной разведки, а не от скрытой части общего состояния.
- [ ] Подготовить App Store описание, privacy policy, скриншоты/иконки, возрастной рейтинг, TestFlight и пройти App Review.

Использовать Xcode Simulator только как дополнительный runtime, если export из этой версии Unity поддерживает выбранную архитектуру Simulator. Он не заменяет физический iPhone по производительности, жестам и виброотклику. Полный ручной прогон на ноутбуке выполняется в Unity Editor Play Mode; подробный процесс и пути обхода несовместимого Xcode — в [плане тестирования](Unity_Test_Plan_ru.md) и [инструкции iOS](iOS_install_ru.md).

## Повтор автоматических проверок ядра

Нужны .NET 8 SDK и Python 3:

```sh
dotnet run --project Tests/CorePlaythrough/CorePlaythrough.csproj -c Release
dotnet run --project Tests/CorePlaythrough/CorePlaythrough.csproj -c Release -- replay
python3 Tools/CheckUiBindings.py
```

Headless-тесты подтверждают правила, стратегии и replay. Они не заменяют ручную проверку Unity/iOS и не свидетельствуют о завершении незакрытых пунктов выше.
